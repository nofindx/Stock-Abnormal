## 1. 产品边界

**只做三件事：** ① 单股异动计算 ② 监控池管理 ③ 全市场预测
**不做：** 资讯、板块行情、资金流、K 线、组合、交易、收益统计；不自动轮询、不推送、不订阅；不登录、不收藏、不同步。
**市场范围：** 全市场上市 A 股（含北交所）；停牌 / 退市整理 / 上市首日 / 无涨跌幅限制股票计入总数，状态为「不可判定」，不参与命中排序。

## 3. 股票卡片规范（本版核心硬规则）

### 3.1 四要素，缺一不可，多一个不要

| 要素 | 说明 | 示例 |
| --- | --- | --- |
| ① 名称 + 代码 | 名称 14px 粗体，代码 11px 灰 | 比亚迪 / 002594 |
| ② 类型 | 异动类型或预测类型 | 30日严重异常 |
| ③ 当日 / 次日 | 仅预测卡出现 | 当日 |
| ④ 关键数值 | 偏离值（或结束日期 / —） | +203.11 |

**明确去除：** 交易所、板块、监控期、剩余交易日、风险原因、进度条、触发价、起止日期、数据时间、免责声明（卡片级）。
- **数据时间**只在页面级出现一次（顶部「共 37 条 · 14:50」/ 底部「行情 14:52」），不逐卡重复。
- **风险原因**只在单股页状态条出现一行，不进列表。

### 3.2 固定列宽网格：上下严格对齐


| 列 | px | rpx | 对齐 |
| --- | --- | --- | --- |
| 名称 | 72 | 144 | 左，超出省略 |
| 代码 | 60 | 120 | 左，等宽数字 |
| 类型 | 86 | 172 | 左 |
| 当日/次日 | 40 | 80 | 左（监控池为空占位） |

**三条配套约定：**
1. 监控池卡片没有「当日/次日」，该列保留为**空占位**，保证数值列与预测页列位完全一致。
2. ST 标签不插在名称与代码之间（会挤掉代码列），统一追加到类型列末尾，写作「10日严重异常 · ST」。
3. 非股票行（刷新按钮行、筛选行）**禁止**套用 `.stk`。

## 4. 逐页说明

### S1 单股计算 · 状态与四项预警 `pages/stock/index`
1. **搜索框**（76rpx 高）：输入 ≥1 字符触发，250ms 防抖；已选股显示「名称 + 代码」。
2. **股票头**：名称 34rpx 粗 + 代码板块 22rpx 灰（左）；现价 40rpx 粗 + 涨跌幅（右）。涨红 `#D93025`、跌绿 `#0E9F6E`。
3. **状态条**：左 4px 色条 + 状态标签 + **一行**原因（如「10日偏离 +103.42% / 阈值 +100%」）。状态取最高一档：`30日严重异常 > 10日严重异常 > 普通风险提示 > 安全 > 不可判定`。
4. **四项预警紧凑表**：指标 / 当前 / 阈值 / 状态 四列，4 行（3日 / 10日 / 30日 / 10日同向）。触发行浅底 `#FFFCF8`，数值与状态字用档位色。
5. **T+N 入口行**：「T+N 假设计算 ›」。
6. **底注**：`行情 14:52 · 仅供参考，不构成投资建议`。

### S2 单股计算 · T+N 假设表 `pages/stock/forecast`
- **沿用方案 A 表格框架**：时间为行、指标为列，列序固定为
  `交易日(T+N) | 股票% | 指数% | 3日 | 10日 | 30日 | 安全上涨空间`。
- **默认 2 日**，顶部三段切换 `2日 / 5日 / 10日`（选中白底，未选灰底）。切换只改行数，**不重载历史行情**（`/forecast?days=N` 一次取 10 日，前端按 N 截取渲染）。
- 输入：`type="digit"`，失焦或回车即算；空值按 0% 参与计算但**输入框保持为空**；非法值仅该行标红并禁用该行结果，其他行不受影响。
- 改一行只重算该行及后续行（纯本地计算，100ms 内完成，不请求网络）。
- 底部：「清空输入」。刷新行情时保留输入。

### S3 监控池 `pages/monitor/index`
- 顶部一行：左「共 37 条 · 14:50」，右筛选「全部 / 普通风险提示 / 10日严重 / 30日严重」+ 刷新。
- 两组列表（见 §3.3）：「当前监控」在前，「已出监管」在后。
- 每页 20 条，触底加载；仅保留最近 30 个自然日。
- 点卡片 → 该股单股页。

### S4 异动预测 `pages/prediction/index`
- 顶部一行：`全市场 5,412 · 候选 8` + `14:50`（含失败数时追加 `· 失败 12`）。
- 两组：**当日预测** / **次日预测**。当日组同时展示已触发和距离阈值不超过板块单日涨幅上限的未触发候选；已触发卡片增加“已触发”并使用浅红底，盘中回落后恢复普通卡片状态但不从候选列表消失。次日组展示下一交易日仍可能触线的候选。
- 卡片四要素齐全，含「当日 / 次日」列。
- 刷新：仅用户点击触发；成功后若新增命中，在该组标题右侧显示一个 `+3` 小标（无弹窗、无引导语），首次加载不显示。
- 排序：已触发 > 距阈值最近 > 涨跌幅绝对值 > 代码升序。

### S5 异常状态标识（极简）
全部为**一行状态标识**，无弹窗、无 Toast 长文案、无解释性引导：

| 场景 | 表现 | 位置 |
| --- | --- | --- |
| 离线 | 灰条「离线 · 缓存 14:50」+ 右侧「缓存」 | 页面顶部 |
| 刷新失败 | 浅红条「刷新失败」+ 右侧「重试」 | 页面顶部（旧数据保留可读） |
| 无数据 | 列表区一行灰字「无标的」 | 列表区 |
| 数据不足 | 类型列「不可判定」+ 数值列「—」 | 卡片内 |
| 部分失败 | 顶部信息行追加「· 失败 12」 | 预测页 |
| 加载中 | 顶部时间位显示「更新中…」，不遮挡列表 | 页面顶部 |
| 校验错误 | 仅该行输入框红框 | T+N 行内 |

### S6 搜索下拉
- 输入 ≥1 字符，250ms 防抖；匹配优先级：完整代码 > 代码前缀 > 完整名称 > 名称包含。
- **最多 5 条**，超出只提示「继续输入以缩小范围」，不加载第二屏。
- 每行：名称 / 代码 / 板块（ST 追加到板块列）。
- 无结果：下拉内「未找到 A 股股票」；请求失败：「搜索失败，点击重试」。两种文案不同。

### 附：规则与诊断页 `pages/stock/rule`
- 规则版本 `2026-07-06 生效` + 数据源说明。
- 普通异常表（5 板块）、严重异常阈值（`+100/-50`、`+200/-70`、同向次数）。
- **诊断折叠区**：`request_id` / `updated_at` / `data_quality` / `rule_version` + 「复制」。
- 底部三入口：隐私政策 · 用户协议 · 数据源说明（注明不收集账号、手机号、位置）。

## 5. 交互流程

### 5.1 主流程

```
启动 → 读本地缓存（最近股票/筛选/T+N 输入）→ 先渲染缓存数据 → 发起最新请求
                                                    ↓
                                    成功：替换数据 + 更新时间
                                    失败：保留缓存 + 顶部「刷新失败 重试」
```

```
选股：输入 ≥1 字符 → 250ms 防抖 → search → 下拉 5 条 → 点选
      → abnormal → 状态条 + 四项预警（含数据时间、规则版本）

T+N：点入口 → forecast?days=10 → 渲染默认 2 行
     改输入 → 失焦/回车 → 本地重算该行及后续行（不请求网络）
     切 5日/10日 → 前端截取渲染（不重新请求）
     清空 → 全部输入框置空并重算

刷新：点击 → 按钮 loading 且禁用 → POST refresh（幂等键）
     ≤3s 返回快照 / 超时转任务（本次操作最多轮询 3 次）
     成功：更新数值与时间；新增命中在组标题显示 +N
     失败：保留旧数据 + 「刷新失败 重试」
```

### 5.2 状态机（页面级，四态互斥）

```
loading（首次，无缓存）→ 骨架 / 顶部「更新中…」
success（有数据）
empty  （有数据但 0 条）→ 「无标的」
error  （请求失败）    → 顶条 + 旧数据 / 或整页「刷新失败 重试」
```

**规则：** 有旧数据时永不进入整页 error；切换 Tab / 筛选 / 返回时保留筛选项、滚动位置与 T+N 输入。

### 5.3 交互约束（小程序）

- 触控目标 ≥ **88rpx（44px）**；卡片行高 88rpx，整行可点。
- 不使用 `wx.showModal` 解释规则、不弹引导；只用 `wx.showToast`（≤7 字）或不提示。
- 不自动刷新；`onShow` 不触发全市场扫描（避免 Tab 切换打爆后端），仅刷新监控池计数。
- 列表 `page_size=20`，触底加载；不使用 `scroll-view` 嵌套长列表以外的复杂手势。

## 6. 数据字段定义

### 6.1 统一响应

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "updated_at": "2026-11-20 14:50:12",
  "data_quality": "full | partial | cached",
  "request_id": "req_8f3a2c91",
  "rule_version": "2026-07-06"
}
```

### 6.2 搜索 `GET /api/stocks/search?q=`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `ts_code` | string | 如 `300750.SZ` |
| `name` | string | 股票名称 |
| `board` | string | `主板 / 创业板 / 科创板 / 北交所` |
| `is_st` | boolean | ST / *ST |

### 6.3 单股 `GET /api/stocks/{ts_code}/abnormal`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` / `ts_code` / `board` | string | 名称、代码、板块 |
| `price` | number | 现价 |
| `change_pct` | number | 涨跌幅（%） |
| `quote_time` | string | 行情时间 `14:52` |
| `data_state` | enum | `realtime / delayed / last_trade_day / insufficient` |
| `status` | enum | `severe_30d / severe_10d / ordinary / safe / unknown` |
| `reason` | string | 一行原因（≤30 字） |
| `alerts[]` | array | 四项预警 |
| `alerts[].key` | enum | `dev3 / dev10 / dev30 / same_dir10` |
| `alerts[].label` | string | 指标名 |
| `alerts[].current` | number \| null | 当前值（null → 显示 `—`） |
| `alerts[].threshold` | string | 阈值文本，如 `+100/-50` |
| `alerts[].state` | enum | `triggered / not_triggered / unknown` |

### 6.4 T+N `GET /api/stocks/{ts_code}/forecast?days=2|5|10`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `rows[]` | array | 每个交易日一行 |
| `rows[].trade_date` | string | `11-21` |
| `rows[].t_offset` | number | 1…10 |
| `rows[].stock_pct` | number \| null | 用户输入（null = 空，按 0%） |
| `rows[].index_pct` | number \| null | 同上 |
| `rows[].dev3 / dev10 / dev30` | number \| null | 重算后的偏离值 |
| `rows[].safe_room` | number \| string | 剩余空间；已触发为 `"triggered"` |

> `days` 只控制**返回行数上限**；前端固定按 10 日预取一次，切换 2/5/10 不产生新请求。

### 6.5 监控池 `GET /api/monitor-pool`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `pool_status` | enum | `monitoring / exited` |
| `name` / `ts_code` | string | — |
| `monitor_type` | enum | `ordinary / severe_10d / severe_30d` |
| `type_label` | string | 前端直出，如「30日严重异常」 |
| `value` | number \| null | 当前偏离值（`exited` 时为 null） |
| `end_date` | string | 结束日期（`exited` 时显示在数值列） |
| `groups[]` | array | `monitoring` 组在前，`exited` 组在后 |

查询参数：`status=monitoring|exited|all`、`type=all|ordinary|severe_10d|severe_30d`、`page`、`page_size=20`。

### 6.6 预测 `GET /api/predictions`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `scope` | enum | `today / next_day` |
| `name` / `ts_code` | string | — |
| `type_label` | string | 命中规则名 |
| `day_label` | string | `当日 / 次日` |
| `value` | number \| null | 偏离值（null → `—`） |
| `scan_total` / `candidate_total` / `failed_total` | number | 扫描 / 命中 / 失败 |
| `quote_time` | string | — |
| `new_hit_count` | number | 本次刷新新增命中数（首次加载为 0） |

`POST /api/predictions/refresh` 返回 `refresh_id / scan_status / scanned_total / candidate_total / failed_total / quote_time`，幂等键防重复任务。

## 8. 关键实现说明

### 8.1 列对齐（本版最容易踩坑的点）

用 **CSS Grid 固定列宽**而非 `flex + gap`。`flex + gap` 下名称字数不同会依次推走代码 / 类型 / 数值列，同一列表各行起点不一致。

```css
/* 反例 —— 不要用 */
.row{display:flex;gap:6px}
/* 正例 */
.stk{display:grid;grid-template-columns:144rpx 120rpx 172rpx 80rpx 128rpx;column-gap:12rpx}
```

数值列必须 `text-align:right` + `tabular-nums`，否则 `+9.98` 与 `+203.11` 右边缘参差。

### 8.2 小程序落地要点

| 事项 | 做法 |
| --- | --- |
| TabBar | 用 `app.json` 官方 `tabBar`（3 项），不自绘、不用 `custom-tab-bar` |
| 安全区 | 底部 `padding-bottom: calc(50px + env(safe-area-inset-bottom))`；iPhone SE 自动回落 |
| 状态栏 | `wx.getWindowInfo().statusBarHeight`，刘海屏/灵动岛不写死 44 |
| 输入 | `type="digit"` + `bindblur` 与 `bindconfirm` 双触发；不用 `bindinput` 逐字重算 |
| 列表 | `wx:for` + `wx:key="ts_code"`；20 条/页；`onReachBottom` 触底加载 |
| 防重复 | 刷新按钮 `loading` + `disabled`；`POST refresh` 带幂等键，重复点击不建重复任务 |
| 防抖 | 搜索 250ms；`Promise` 序号校验，旧请求结果不覆盖新关键词 |
| 缓存 | `wx.setStorageSync` 只存最近股票、筛选、T+N 输入；**不存全市场行情** |
| 主包 | 纯文本 + 原生组件，无图片资源、无自定义绘制，主包远低于 1.8MB |
| 合规 | 生产只走 HTTPS 自有域名；Tushare Token 只在后端；阈值由后端下发，前端不写死 |

### 8.3 性能与降级

- 首屏：先读本地缓存渲染，再请求；1.5s 内出可操作骨架。
- T+N 切换 2/5/10 **不产生网络请求**（一次取 10 日，前端截取）。
- 预测刷新超时（>3s）转任务态，本次操作最多轮询 3 次后停止。
- 并发：同一股票同一交易日请求合并；后端快照复用，禁止小程序端循环请求单股。
- 离线：展示缓存并标注「离线 · 缓存 HH:mm」+「缓存」标签；刷新按钮置灰，不伪造实时。

### 8.4 风险与合规

- 数值缺失一律显示 `—`，**不用 0 补齐**；类型列转「不可判定」。
- 每页底部固定「仅供参考，不构成投资建议」。
- 不提供买卖建议、目标价、荐股；详情页不设交易入口。
