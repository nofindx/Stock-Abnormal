# 版本发布记录

## 1.0.3（2026-10-22）

- 小程序上传版本：`1.0.3`
- 产品规则（v60）：10 日同向基于收盘行情识别达标三日窗口；同方向连续重叠窗口归并为一次独立事件，已核验普通异动公告的重置边界切分事件段；事件起始交易日落在最近 10 个共同有效交易日内时计入，滑出后移除。上涨、下跌分开统计，换手率无方向事件不计次。该去重口径是产品推断，交易所没有明确数学窗口去重说明。
- 事实解析：普通异常公告正文识别支持连续两日或三日阈值事实，确保如冰山冷热公告中的两日累计偏离事实能够落入可审计 `resetFacts` 并建立后续计算边界；未确认官方正文的公告不触发行情重置。
- 重置口径：经正文核验的普通异动公告只重置三日普通基线；严重异动公告重置 10 日同向账本及 10/30 日严重指标，不重置三日普通指标。两种重置范围均作为产品口径维护。

- 自动化验证：后端 192 项 unittest 通过；Python `compileall`、小程序 JavaScript `node --check`、`app.json` JSON 解析和 Git whitespace 检查通过。
