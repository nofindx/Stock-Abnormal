### 真机简验范围

- [ ] **单股页面**：名称、价格、日期、状态和四项预警正确；模拟计算初始即显示百分号，“距最近阈值”为到最近上涨阈值所需的剩余涨幅；清空恢复默认值。
- [ ] **异动预测**：当日/次日显示正确；全时段首次进入获取最新报价，切标签或返回不重复获取，手动刷新有效；次日不重算未来条件，预测卡与单股同上下文结果一致。
- [ ] **重点监控**：有效期及剩余天数正确，切标签不闪现旧卡；凡拓原严重期 `20261026–20261106` 不被同一公告的后发提示延长。
- [ ] **公告阅读**：有有效公告阅读入口时，点击后在小程序内打开PDF并能正常返回；普通、严重、退市整理有有效样本时分别检查。没有有效样本不标通过，也不为凑样本创建生产事实。
- [ ] **失败提示**：网络或实时刷新失败时有明确提示，不把旧结果当新行情，不把未知变成安全或0次。

`1.0.18`历史真机结论保留；上述范围复验新候选相关改动，不要求重做跨系统全集测试。

## 3. 正常运行时顺带抽查

不购买资源、不制造故障、不专门等待完整跨日演练。发布前遇到相应时段可先核对，发布后首个交易日继续观察：

- [ ] 盘中：只刷新已发布名单或所选个股，报价时间与日期真实，正常请求无持续错误。
- [ ] 收盘后：当日结果、下一交易日预测、单股对应数值一致。
- [ ] 夜间公告后：普通公告计次及3日重置、严重公告按 `effective_date` 四项重置正确；监管有效期与页面一致。
