# 产品规则证据认定标准

版本：EVIDENCE-POLICY-NEXT-20261029.2
适用：vNext 规则包发布门禁 G21

## 1. 本版本的规则权威

本版本按已确认的 `product_policy` 执行，不要求每一项规则另有交易所网页证据。产品规则由 PRD、规则目录和可重放夹具共同组成，运行时只接受版本化 manifest 中 `source_type=product_policy`、`review_status=approved_by_product` 的条目。

外部链接、公告正文和公开案例可作为补充材料，但不是规则包发布前提；产品定义不冒称交易所书面定义。

## 2. 必须封存的证据字段

每条影响计算结果的规则至少保存：

- 板块或证券情形；
- 产品规则版本、生效日和适用截止日；
- `policy_basis`；
- `fixture_refs`；
- 规则内容 SHA-256；
- 审核人和审核时间；
- `rule_key`、适用范围和该证据覆盖的参数/边界。

规则记录必须能在不依赖当前网页内容的情况下重放判断。夹具缺失、规则版本缺失、哈希与封存内容不一致，或条目未获产品批准，都不能通过 G21。

## 3. 产品规则条目

```text
source_type=product_policy
review_status=approved_by_product
```

产品口径必须写明规则依据和复算夹具。存在冲突或无法重放时标记 `pending_verification`，阻断受影响规则包发布；不把缺证据转换成“安全”。

## 4. G21 通过条件

一个可发布规则包必须覆盖四个板块及会改变结果的边界：四项阈值、基准指数映射、收益构造、除权、普通事项停复牌、严重异动停复牌、复牌首个有效收益日、普通公告重置、严重公告重置和正式生效日期。每项都要有明确批准的产品口径、内容哈希和可重放夹具。

当前仓库的 manifest 已切换为 `approved_by_product`，G21 由 `evidence_gate` 校验。
