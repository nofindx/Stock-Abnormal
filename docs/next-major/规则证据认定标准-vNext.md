# 规则证据认定标准

版本：EVIDENCE-POLICY-NEXT-20261029.1  
适用：vNext 规则包发布门禁 G21

## 1. 什么才算官方规则

只有下列来源可以作为 `source_type=official` 的候选：

1. 交易所官网发布的现行交易规则、业务指南、正式公告或其官方 PDF/HTML 原文。
2. 交易所官网明确指向的正式规则附件，且能够保存原文内容和下载地址。
3. 交易所正式公告中对某项异常波动、停牌、复牌、退市整理或监管期限作出的明确事实说明。

监管软件、第三方行情平台、雪球、媒体、专家意见、豆包/WorkBuddy 回复和现有代码测试，都只能作为检索线索或产品推断依据，不能单独把规则标为官方。

## 2. 必须封存的证据字段

每条影响计算结果的规则至少保存：

- 交易所、板块或证券情形；
- 官方标题、发布日、主施行日和适用截止日；
- `source_url`；
- 条款号、章节或 PDF 页码；
- 必要原文摘录；
- 页面/PDF 内容 SHA-256；
- 抓取时间、审核人和审核时间；
- `rule_key`、适用范围和该证据覆盖的参数/边界。

证据记录必须能在不依赖当前网页内容的情况下重放判断。链接失效、正文不可读、只有标题没有条款、或哈希与封存内容不一致，都不能通过 G21。

## 3. 官方明文与产品口径分层

官方原文明确写出的阈值、板块适用范围、公告事实、停牌/复牌和生效日期标记为：

```text
source_type=official
review_status=approved
```

官方没有直接说明、但为产品实现所必需的推断（例如重叠窗口如何构成独立计次）标记为：

```text
source_type=product_policy
review_status=approved_by_product
```

产品口径必须写明推断依据、公开案例和复算夹具，不能在界面或文档中冒称交易所书面定义。存在冲突或无法重放时标记 `pending_verification`，阻断受影响规则包发布；不把缺证据转换成“安全”。

## 4. G21 通过条件

一个可发布规则包必须覆盖四个板块及会改变结果的边界：四项阈值、基准指数映射、收益构造、除权、普通事项停复牌、严重异动停复牌、复牌首个有效收益日、普通公告重置、严重公告重置和正式生效日期。每项都要有已审核官方证据，或有明确批准的产品口径和可重放夹具。

当前仓库的 `server/fixtures/vnext/rule_evidence_manifest.json` 仍为 `blocked_pending_review`。在责任人封存上述证据、补齐哈希和夹具前，不能把 vNext 直接标为规则门禁通过。
