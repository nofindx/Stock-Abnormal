## 以后怎么归档

1. 仍要指导开发或运维的文档，更新在 `docs/`。被替代的稿件和阶段报告交给 Git 历史保存。
2. 复核某个版本必须用到的回执、源码提交和验收结论，集中在 `releases/<版本>/`。冻结标签用于恢复源码，ZIP 用于直接解压，只有需要离线包时才导出。
3. 发布目录保留关键回执和最后一轮验收。逐轮日志、截图和中间代码从对应 Git 提交查阅。独立仓库里未提交的历史成果保存在 `archive/` 的本机冻结包。
