# 异动查查：最新设计与工程说明

> 版本：2026-09-29
> 这份文件是当前代码、页面结构、数据口径和上线验收的单一设计参考。实现与旧设计冲突时，以本文件和正式 PRD 的最新条款为准。

## 1. 产品边界

小程序只提供三项能力：单股计算、当前监控池、异动预测。它是个人开发者的规则计算工具，不提供交易、荐股、资讯流、账户体系、历史监控页或自动轮询。

## 2. 页面设计

### 2.1 单股计算

- 顶部只有股票搜索框，未选股时显示五层居中引导。
- 选股后显示状态卡：股票名、代码、板块文字、现价、涨跌幅和“状态安全/状态异常”。安全使用浅绿色，异常使用浅红色。
- 四项指标使用两列圆环卡。左侧是指标名、当前偏离值、阈值；右侧是同色圆环。圆环中心只显示剩余百分比、剩余次数、已触及或 `--`。当前偏离值和圆环数值使用圆环同色；圆环和文字留出一致的内边距。
- 模拟计算默认展示 2 个交易日；只提供“10日计算”展开按钮。切换股票后重新收起。输入股票/指数涨幅只在本地重算，不发网络请求。
- 底部固定为隐私政策、用户协议、规则说明三个入口。

### 2.2 监控池

- 不显示页面大标题，不提供历史监控入口。
- 第一层：全部、风险提示、严重异动。
- 第二层：去 ST 开关和条数信息。
- 第三层：数据更新时间与刷新入口；下拉刷新只更新数据，不旋转按钮。
- 监控卡按剩余交易日升序。当前监控结束日当天仍显示，次日移除。非关键标的名称和代码降低对比度，但仍保留在列表中。
- 仅 10 日/30 日严重异动提供公告控件；风险提示不显示公告入口。公告只传链接，PDF 在严重异动期间由后端临时代理，结束后清理。

### 2.3 异动预测

- 当日/次日是纯切换，不触发刷新。
- 数据更新时间区复用监控池的结构和对齐方式。
- 股票卡三行：名称+代码+当前价格/涨跌；10 日偏离与触发条件；异动规则。关键数据不换行。
- 盘前、盘中、收盘待确认、Tushare 已入盘使用同一规则，只切换数据时点，并明确显示数据阶段和质量。

## 3. 颜色与字体

页面底 `#F2F3F5`，卡片 `#FFFFFF`，弱背景 `#FAFBFC/#F7F8FA`，主文字 `#1A1A1A`，次文字 `#6B7280`，辅助文字 `#9CA3AF`。30 日严重异动 `#C0271E`，10 日严重异动 `#E0501F`，普通风险 `#8A6D0B`，安全 `#128A5F`，涨跌 `#D93025/#0E9F6E`。字体为 `-apple-system, BlinkMacSystemFont, "PingFang SC"`，数字使用等宽数字。

## 4. 后端业务与数据源

- Tushare 是股票基础资料、交易日历和正式收盘数据主源；腾讯为实时行情主源，新浪、东方财富依次备援。
- 18.cn 是监控公告主源；巨潮资讯仅在主源可用时作佐证，主源失败时接替。两源都失败时保留旧的当前数据集；没有旧数据才返回错误空态。
- 监控分类只由公告正文语义判断：普通风险必须出现“交易所将对以上证券的异常交易行为进行从严认定”或等价表达；10 日/30 日必须同时出现对应交易日窗口和约 100%/200% 阈值语义。只写“严重异常波动”而没有窗口与阈值，不自动归类。
- 单股和预测共用纯函数规则模块，后端只存股票基础资料、近 30 个交易日收益率向量、指数收益率向量、任务状态和预测数据集，不存原始日线、成交量、换手率和用户输入。

## 5. 时间与降级

| 阶段 | 结果使用 | 前端提示 |
| --- | --- | --- |
| 盘前 | 最近已确认交易日收盘数据 | 最近交易日 |
| 盘中 | 股票与所属指数实时行情同时成功才临时修正 | 实时可能延迟 |
| 收盘后未入盘 | 实时源临时收盘数据 | 收盘价待确认 |
| Tushare 已入盘 | 正式收盘数据重算 | 已确认 |

不能混用不同交易日或只用单边实时行情。实时失败返回最近已确认结果并标记延迟；后台失败保留旧数据集；无旧数据才显示错误空态。

## 6. 性能与稳定性

- 股票基础资料和 30 日收益率每日 00:00 后更新，成功后当天不重复；进程内读取缓存最多 6 小时，CloudBase MySQL 是跨重启的最小持久层。
- 监控公告每日 00:00 后采集；次日 01:00-09:00 每小时重试。小程序刷新只读取已成功数据集，不触发采集。
- 预测刷新只处理当日候选行情，不逐只请求全市场；重复任务用 MySQL 租约合并。
- 页面首次进入先渲染同构骨架和上次成功数据；请求超时保留旧数据，且显示错误/过期状态。
- API 使用标准库线程 HTTP 服务，健康检查为 `/health`。服务端凭证只通过环境变量注入。

## 7. 验收清单
