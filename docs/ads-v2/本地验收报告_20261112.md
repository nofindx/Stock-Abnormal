## 2. 已交付能力

1. 四个独立展示位置：首页历史栏下、预测列表末尾、模拟计算上方、监控列表末尾。公告/PDF、隐私与规则页面不放广告。
2. 两个激励入口：10日计算和已就绪的次日预测。用户确认后展示；只有完整观看回调与有效会话同时成立才解锁。
3. 换股、重置与跨日期的迟到回调隔离；重复点击合并；提前关闭、广告错误、缺失完成标记均不发奖。
4. 同日S1/S2更新保留模拟输入、当前2/10日布局与有效许可；清空输入保留当前布局。次日同目标重试不要求再次观看，目标变化需重新解锁。
5. 独立公开配置接口与次日就绪元数据接口；配置校验、600秒进程缓存、60秒失败退避、并发合并及no-store响应。
6. 默认广告关闭、两项功能免费；无真实广告ID也可保持原功能。新增本地模式只允许127.0.0.1请求，不回退云托管。

## 4. 后续接入与发布条件

当前尚未满足用户提供的流量主UV门槛，保持关闭配置。满足资格并取得真实广告单元后，补验以下内容：

- 在对应AppID后台确认4个展示单元、2个激励单元的模板、场景许可和审核状态。
- iOS/Android验证真实视频完整观看、提前关闭、无填充、网络错误、页面返回、换股和跨目标日期；确认官方素材布局、点击区域与关闭能力。
- 验证配置开启/关闭、两功能独立许可、同页两个展示位置，以及真实客户端的加载耗时和页面体验。
- 进入另行授权的发布阶段后，退出本地模式、恢复原云托管链路，再验收旧包兼容及候选前后端，更新审核与隐私材料。

本地开关仅隔离小程序请求；如以后启动本地完整后端联调，仍需提供隔离的数据配置，不得加载生产数据库或Redis配置。真实广告测试不会以伪造ID或模拟回调替代。

## 6. 页面缓存与开发路由补验（ads-local.2）

按用户本轮要求，异动预测双标签、重点监控分类和单股重复查询增加页面内存复用；跨日/业务阶段自动失效，手动请求继续刷新，不永久保存行情或token。重点监控PDF地址到期按需续取。低配后端优化为待实施方案，没有混入当前完成项。

上一轮将“本地开发”错误收窄为“默认只能连本地后端”，本机未运行8787时无法取得行情。现已恢复冻结版develop HTTPS、trial/release callContainer路由。用户仅需在开发者工具重新编译以加载修复；尚未取得重新编译后的可视化或手机验收。

本轮前端15个测试文件通过，JS语法33个文件、JSON及组件引用12个文件通过，wcc编译7个WXML、wcsc编译8个WXSS通过；时间边界探针3项及后端release测试3项通过。本轮后端仅同步候选releaseId，未修改业务后端；没有重复运行此前已通过的442项后端全量测试。

新增验证：预测标签切回0次业务读取、每标签独立token、最新S2恢复、失败提示保留、旧回包隔离、不可用剔除；单股8只LRU与跨日更新、模拟会话仍重置；监控同一完整列表筛选与倒计时一致、PDF过期续址及失败、默认App实际请求路由。未连接生产数据库或Redis执行本地后台任务。
