# 分享与保存：隐私配置、真机验证和提审说明

> SHARE-REVIEW-20261116.1。底部仅“发给朋友”和“保存图片”。2.0.3 / 20261115.2已于2026-11-17正式上线。隐私指引已完成，备案已由用户确认完成。本地与线上接口同版，上传记录及最新证据见[整体复核](整体复核与版本对齐_20261116.md)。

## 1. 本次实际行为

| 动作 | 行为 | 授权 |
| --- | --- | --- |
| 打开页面、选股、查询、刷新、模拟 | 沿用现有功能 | 不为保存预先申请授权 |
| 发给朋友 | 微信原生好友/群小程序卡片；封面为当前状态与四项预警，打开为该股默认2日空白输入态 | 不申请相册权限、不读取联系人 |
| 保存图片 | 本机生成完整当前页面：状态卡、四项预警、当前2/10日模拟、所有已填写输入及结果，直接保存设备相册 | 用户点击后才调用微信保存API，请求必要隐私授权及相册写入授权 |
| 拒绝、取消或失败 | 提示未保存，允许后续主动重试 | 不影响查询、计算或好友分享，不循环索权 |

不读取或上传用户相册；不上传生成图片、模拟输入或搜索历史；不自动分享、保存或要求用户授权后才能用基础功能。保存图片无可点击的小程序入口，不生成额外二维码。底部不再提供朋友圈按钮或综合图片分享菜单。右上角微信原生菜单保持现状。

## 2. 管理员在微信后台要做什么

1. 登录该小程序的微信公众平台，进入 **设置 → 服务内容声明 → 用户隐私保护指引**。平台界面若调整，以当前后台入口为准。
2. 为`wx.saveImageToPhotosAlbum`声明对应的相册写入/保存图片用途，按后台实际给出的隐私类型选择；不要为本功能增加读取相册、摄像头、麦克风、联系人、手机号或位置等项目。
3. 用途建议填写以下文字；后台字数受限时使用下方短版。联系人、运营主体等必填项填写真实资料，不在仓库中留存私人联系方式。
4. 提交并确认平台生成的隐私指引与小程序内协议一致。官方指引说明补充隐私类型约5分钟后生效；生效后再验证新开发包。单纯改本地协议不等于完成后台声明。
5. 提审时按真实接口及后台提示填写隐私信息，**不要沿用“任何权限均不使用”或与保存接口不一致的“未采集隐私”声明**。使用相册写入能力不代表读取或上传相册，两者须在用途里区分。

**用途完整文案：**

> 仅当用户主动点击“保存图片”时，将页面当前显示的股票状态、四项预警及模拟计算图片（包含当前2/10日和已填写输入）保存至用户设备相册。不读取用户相册中的照片或视频，不上传相册内容。拒绝授权不影响查询、计算及好友分享。

**短版：**

> 用于用户主动保存结果图片至设备相册，仅写入，不读取或上传相册内容。

**替换原“不要任何权限”的说明：**

> 查询、计算及好友分享不申请相册权限。仅在用户主动保存图片时申请必要的相册写入授权；不读取相册，拒绝不影响其他功能。

应用代码使用微信原生保存接口的授权流程，无启动索权或自定义强制隐私弹窗。`app.json`的`permission`文档目前未提供相册用途描述项，不额外添加`permission.scope.writePhotosAlbum.desc`；后台声明与运行时相册scope授权分别完成。

## 4. 真机验收表

| 场景 | 通过标准 |
| --- | --- |
| 新安装/清除授权后的首次打开 | 无启动相册授权；查询、刷新、计算可用 |
| 首次点击保存并允许 | 必要的微信隐私/相册授权后直接落图；无综合分享菜单；确认相册实际有图，而非仅看成功toast |
| 拒绝隐私/相册授权 | 提示未保存，按钮恢复；查询、模拟、好友分享可用，无循环弹窗 |
| 拒绝后重试/设置中授权后重试 | 微信可能不重复弹窗；用户可管理授权，再主动保存成功。官方隐私弹窗拒绝不足10秒可能直接返回拒绝，不能判为应用卡死 |
| 已授权后重复保存 | 每次主动点击直接保存，快速连点只生成一份当次任务 |
| 换股/清空/跨业务阶段/离开 | 迟到的导出不发起旧图保存；已调用系统保存的操作不能撤回 |
| 自定义模拟或展开10日后保存 | 图片完整保留当前状态、四项、2日/10日布局、实际填写输入和结果；页面不重置；无搜索历史或接口凭据 |
| 好友/群分享和冷/热打开 | 原生卡片正确；接收者进入同股默认2日，不继承模拟和解锁 |
| iOS和Android | 分别确认授权、拒绝、实际图片内容、长图可读及按钮横排；权限行为以各客户端为准 |

自动化只覆盖API替身，不能证明微信后台声明、系统相册授权或实际落图已通过。

## 6. 常见失败如何定位

- `api scope is not declared in the privacy agreement`或`errno=112`：核对后台声明及生效时间、AppID和新包，不能靠重新授权或修改数据库修复。
- `appid privacy api banned`：核对是否曾以“未采集隐私”提审或未声明协议；按微信后台提示补正/恢复权限，不承诺只改代码即可解禁。
- 用户拒绝、取消或系统相册限制：不报保存成功；按微信设置及操作系统实际授权检查，不引导无关权限。
- API不支持或系统写入失败：提示失败并保留其他功能；不降级打开包含用户未要求选项的综合分享菜单。
