> ADS-V2-20261114.9；2026-11-14；在已确认广告方案上增加单股整页分享；分享卡片与双入口本地实现已调整，真实客户端分享待验。

## 1. 产品范围与广告形态

本版接入微信官方广告，包含4个页面展示广告位和2个激励视频解锁入口。展示使用 `ad-custom` 原生模板；激励视频使用 `wx.createRewardedVideoAd`。广告位创建、模板能力及使用场景均需由实际流量主后台确认，不将本设计视为平台审核保证。

普通股票查询、实时行情刷新、四项预警、股票状态、重点监控、公告阅读、默认2日模拟和当日预测继续直接使用。10日模拟和异动预测页面的次日列表，按本稿条件主动观看完整激励视频后使用。不增加支付、会员、登录、账户、插屏、第三方SDK或应用自建定向广告。

广告与计算分离：广告不会改变价格、规则阈值、计次、重置、预测名单、监管期限、数据质量或公告事实。展示广告不是股票/公告卡；激励解锁是本地功能展示许可，不是股票风险状态。

## 2. 开通前置条件与冻结边界

用户提供的当前条件为累计独立访客UV > 100、无刷粉且未曾有严重违规记录，目前未满足。UV去重、资格、开通和广告位审核由微信平台确认，不能用本地计数推定已经开通。

当前1.0.21保持完整冻结，原有10日模拟和次日预测不因设计新方案而加锁；每日行情、公告及预测作业照常运行。本版开发可在未开通前开展，生产激励功能启用须等取得真实单元并通过实际测试。没有资格/ID时只测试默认关闭和模拟事件，不请求虚构、他人或其他AppID广告位，不把模拟通过当成投放通过。

2.0.0不在广告尚不可用时启用观看门槛，也不将不可用占位包替换当前审核版。配置将“功能免费开放”和“激励解锁”明确区分，避免广告默认关闭却把现有功能永久锁住。

## 3. 四个展示广告位

| placement | 位置 | 可见条件 |
| --- | --- | --- |
| home_history_below | 首页历史栏正下方；现有历史行与引导/详情区之间 | 历史栏已正常渲染，配置允许；没有历史记录时仍可显示，不依赖行情S1 |
| prediction_footer | 异动预测当前标签列表末尾、法律页脚之前 | 已成功读取且至少1张业务卡；次日未解锁时不显示其列表或列表广告 |
| stock_simulation_above | 单股详情四项预警之后、模拟计算区域正上方 | 已选股、详情正常渲染；不放到模拟区域下方 |
| monitor_footer | 重点监控列表末尾、法律页脚之前 | 当前筛选成功且至少1张监控卡；无结果/整体错误时不显示 |

现有首页与单股计算同属 `pages/stock/index`，不是两个独立页面。因此选股后可能同时看到历史栏下方广告和模拟区域上方广告，最多2个展示广告位；未选股时只有历史栏下方1个。本稿不擅自合并这两个位置。

每个展示位置在同一页面实例至多1次应用层挂载，不在列表中间插广告，不混入业务items、数量、排序、筛选、预测Key或股票跳转目标。监控类型筛选、当日/次日切换复用本页对应广告位置，不能每切一次重新请求。

公告PDF阅读、规则、隐私页不放广告；搜索建议浮层、错误信息、股票卡和模拟表格内部不插广告。首页广告与搜索/历史操作清楚分隔，不能遮挡建议、清空或键盘。

正常详情中的IPO暂不适用、普通/严重监管及单项指标不可用，不影响展示位置资格；整体详情失败时不显示模拟上方广告。广告保留平台标识、关闭入口（若模板提供）及完整素材，不用红黄预警背景包装，不覆盖业务按钮或导航。

## 4. 激励解锁定义

### 4.1 10日模拟

默认显示可直接使用的2日模拟，`10日计算`按钮保留，并附“观看视频解锁”的提示。首次点击先检查模拟基线可用及规则适用性，再说明“完整观看视频，解锁本次页面的10日计算”，用户确认后展示激励视频；取消不展示、不改输入。

仅在官方关闭回调 `isEnded === true` 且请求仍属于当前页面/股票/模拟会话时，记为已解锁并自动展开10日计算。`show()`成功、load成功、计时到点、提前关闭或缺失结束状态均不能作为成功依据。展开时保留原2日已输入值，沿用现有算法生成后续8日，不额外获取行情、不改生产数据。

同一次有效模拟会话中，已解锁后再次点击不重复要求视频。IPO暂不适用、交易/行情条件不支持模拟、基线不完整时先说明原因，不让用户看完再发现不能计算。已经解锁也不能绕过规则适用性或数据质量检查。

### 4.2 异动预测的次日列表

只有后端确认收盘后的下一目标交易日初态或后续正式预测已发布、当前阶段允许且数据可读，才提供激励解锁入口。不能仅按15:00或手机日期推定数据存在，也不能观看广告提前进入尚未开放时段。

首次进入尚未缓存的次日预测时，先检查可用性；未就绪显示现有数据准备原因，不弹视频。已就绪但未解锁时，说明“完整观看视频，解锁本次页面的次日预测”，用户确认后观看；不先切到锁住的空列表，也不提前展示列表内容。同一业务阶段内已加载且有合法会话许可的标签切回直接恢复内存结果，不重复读取元数据或业务列表。跨日/阶段、手动刷新和失效规则见[页面缓存定义](页面缓存与低配优化方案_20261112.md)。

完整观看且页面会话、目标交易日仍一致后，切到次日标签，通过原S1读取对应数据。获奖只控制能否进入页面，不重算次日条件、不扩展名单、不自动增加S2。次日价格刷新仍按原方案执行，不把当前报价计入次日收益。

同一页面会话、同一目标交易日内，切回当日再进入次日不重复看视频；初态升级为正式数据、同目标数据版本更新和read_token续期也不重复看。若成功观看后数据暂时读取失败，保留该会话的解锁权，可直接重试读取，不能要求再看一次。

免费单股状态卡中的现有次日摘要保持原状；本次门槛范围是“异动预测页的次日列表”，不顺带锁住四项预警或单股摘要。入口以数据集已发布且可用为准，不以候选数量决定是否跳过解锁；解锁不保证一定存在候选，若可用数据集为0张，解锁后如实显示“暂无候选”，不能用空结果伪装数据未发布。

### 4.3 页面重置与解锁有效期

解锁不跨页面会话、股票或目标日期，不写入本地持久化存储，不设置“当天全局免广告”。模拟与次日列表是两个独立许可，观看其中一个不能解锁另一个。

| 事件 | 10日模拟 | 次日列表 |
| --- | --- | --- |
| 页面销毁重建、冷启动、显式整页重置 | 清除许可，恢复2日；下次点击需观看 | 清除许可，回到当日；下次进入可用次日需观看 |
| 在原单股页面换股票 | 新模拟会话，恢复2日并清除许可 | 不影响其他仍存活的预测页面会话 |
| 模拟基准交易日改变、整套模拟输入被重新初始化 | 清除许可、恢复2日 | 不影响次日许可，除非目标交易日也变更 |
| 次日目标交易日改变 | 不由此改变当前模拟许可 | 清除旧日期许可 |
| 暂时隐藏、切底部Tab、PDF返回，页面未销毁且日期未变 | 不视为重置，不自动播放 | 不视为重置，不自动播放 |
| 手动刷新行情、同日S1重读、S2报价更新、read_token续期 | 原会话输入未被初始化时保留许可 | 同目标交易日保留许可 |
| 模拟“清空”按钮 | 仅清空数值，不是整页重置；按当前2/10日布局恢复默认，保留许可 | 无影响 |
| 预测当日/次日切换、监控筛选 | 无影响 | 同会话同日期保留许可 |

“清空输入”与“页面重置”在本稿明确区分，保持先前已确认的清空规则：未展开恢复2日默认，已展开恢复10日默认；不擅自把清空变成强制再看广告。若未来增加整页重置按钮，它须清楚标注会恢复初态，不能复用清空图标暗中增加行为。

### 4.4 取消、失败与业务隔离

提前关闭提示“尚未完整观看，未解锁”；无填充、无效ID、广告位审核/关闭、基础库不支持、网络失败、load/show错误提示“广告暂不可用，请稍后重试”，保持原免费界面和已输入值，不自动放视频、不死循环、不隐式发放许可。用户可再次主动点击尝试，应用不后台重试。

此处修订旧稿“广告失败不影响全部功能”的过宽说法：展示广告失败不影响功能；激励失败不新增解锁，10日模拟/次日列表保持未解锁，其他查询、2日模拟、当日预测、监控及PDF正常。业务数据失败与广告失败分别说明，不能互相伪装。

运营可以通过明确的feature gate配置把某功能切为free，以暂时免费开放；这不是把广告失败当成观看完成。已发放许可不因同会话配置短暂过期或广告加载错误而收回；资格/业务日期仍须有效。

### 4.5 回调与重复点击

激励实例遵循微信官方的页面内生命周期，不跨页面复用。共用控制器负责逻辑，不保存跨页广告实例。每次用户发起观看生成attemptId并捕获pageSessionId、功能及对应股票/基准日或次日目标日期。

连续点击只启动1次展示；同一完成回调最多发放1次许可。观看期间页面销毁、换股、整页重置、业务日期切换后，旧回调不解锁新会话；返回时提示状态已更新，不自动发起第二个视频。广告导致的正常onHide/onShow本身不是页面重置。退出、失败后清理本次监听，避免累积重复发奖。

不按固定秒数模拟观看完成，不把没有结束信息的旧回调视为完整观看；不支持可靠结束判定的环境直接说明暂不可用。微信客户端提供的回调是本版正常流程依据，不宣称具备服务端防篡改证明。

## 5. 加载、缓存与架构

### 5.1 两类广告各自管理

展示广告沿用已同意的策略：每个位置每页面实例至多1次应用层挂载，不传ad-intervals，不定时轮播；切标签、返回、筛选、手动刷新及行情更新不主动重建。首页位置可以在历史栏就绪后加载，其他展示位置等待相应业务S1成功；均不阻塞S1/S2和内容展示。

激励视频与上述自动加载分开：仅用户主动点击解锁并确认后展示。主动重试未成功的观看、页面重置后再次点击，是新的显式操作，不因“每页面展示广告至多一次”而禁止。两类广告都不触发额外行情刷新，不自动播放激励视频。

无广告不显示空壳。error后按官方组件规范处理外层容器，不频繁销毁/重建而丢失load回调；不把不可见1px组件放屏外请求广告。显示/隐藏方式须符合选定模板规范，不能保留透明点击区域造成误触。

### 5.2 前端单元

- `components/official-ad`：4个展示位置复用，封装官方ad-custom和布局、load/error。
- `utils/ads-config`：轻量配置、进程内缓存和并发请求合并，不依赖业务授权token。
- `utils/rewarded-access`：共用激励流程与会话许可管理；实例由各页面持有，许可不落库、不跨页保存。

私有广告状态和解锁状态不并入股票状态、监管状态或数据可用枚举。单股入口在expandSimulation之前判断，预测入口在switchScope切标签之前判断，不复制两套计算。

本版是小程序功能展示门槛，不是后端收费数据授权：模拟原本在前端，既有后端API也不因广告修改S1/S2权限。真实防绕过验证若有后续需求，应另外确认平台支持的服务端证据及权限方案，不能以本地布尔值宣称服务器已验证观看。

### 5.3 后端配置契约

保留新增公开只读 `GET /api/client-config`，沿用云托管入口，不读取行情/公告/MySQL/Redis，不创建S1/S2上下文。首版随部署维护固定映射/开关，不开发运营管理后台。示例为尚未开通时的关闭配置：

```json
{
  "code": 0,
  "data": {
    "configVersion": "ads-v2-2",
    "ads": {
      "enabled": false,
      "allowedVersions": ["2.0.0"],
      "cacheTtlSeconds": 600,
      "placements": {
        "home_history_below": {"enabled": false, "type": "ad-custom", "unitId": ""},
        "prediction_footer": {"enabled": false, "type": "ad-custom", "unitId": ""},
        "stock_simulation_above": {"enabled": false, "type": "ad-custom", "unitId": ""},
        "monitor_footer": {"enabled": false, "type": "ad-custom", "unitId": ""}
      },
      "rewarded": {
        "simulation_10d": {"enabled": false, "type": "rewarded-video", "unitId": ""},
        "prediction_next": {"enabled": false, "type": "rewarded-video", "unitId": ""}
      }
    },
    "featureGates": {
      "simulation_10d": {"mode": "free"},
      "prediction_next": {"mode": "free"}
    }
  },
  "message": "ok"
}
```

四个展示位置和两个奖励场景各有独立逻辑ID与开关，建议分别创建平台广告单元便于统计；后台如对同页实例/单元有约束，以实测能力修订，不静默违规复用。广告ID不是密码，不在配置中放签名密钥或数据源凭据。

功能mode仅有free/rewarded：free直接使用；rewarded需有效会话许可。启用rewarded之前必须满足对应广告开关、支持形态、有效单元和真机验证；若运行时无广告或配置矛盾，不发许可，保持未解锁并显示原因。全局广告关闭会停止新的广告请求，不自动把rewarded变free，运营恢复免费须同时显式设置featureGates。

配置成功后600秒进程内有效，不落磁盘；并发合并为1个请求，失败后60秒不自动重试，无重试定时器。在冷启动、页面可见或用户主动解锁时按需检查；未知版本/形态、格式错误、空ID和超时不请求广告，不能凭缺失配置推定观看门槛。配置首次不可用时以本版内置free默认提供原功能，后续已确认rewarded的会话遇配置失效则停止新观看、提示重试，不把失败偷偷改成免费发奖。

不长时间缓存远程开启状态，不用CDN长缓存叠加关闭延迟。急停优先关闭微信广告单元；配置作为补充，不保证600秒内全终端即时关闭，不增加常驻轮询。已有许可按会话/日期规则保持，不伪装取消观看事实。

### 5.4 数据与基础设施

不新增MySQL表、Redis键、用户体系、跨实例广告锁，不迁移数据库、不重算预测、不重抓基础行情和公告。Redis继续原有业务职责。后端不代理或存储广告素材，收入、UV、曝光采用微信后台口径；load不等于有效曝光，show不等于完整观看，不自行反复点击广告测试收入。

## 6. 隐私、平台审核与版本发布

实际开通后核对官方组件、激励视频适用场景、流量主协议、个人主体结算/税务及隐私要求。更新隐私页、公众平台说明和审核备注，明确4个展示位置、2个自愿观看入口、未完整观看不解锁及免费功能范围，不能继续写成“全部功能无广告门槛”。

不为广告新申请手机号、位置等无关权限，不上传本地搜索历史或模拟输入，不将股票风险等级传作自建广告定向。保留官方广告标识，不引导点击广告、不承诺观看带来投资收益。

先开发默认关闭路径，取得真实广告位后测试奖励完整闭环，再同步2.0.0前后端元信息与材料提审。审核时须能验证实际激励功能，不隐藏真实功能或提供与拟发布行为不同的绕过路径。若平台对该场景不允许激励广告，应先调整产品方案，不规避平台限制。

生产开启可分批进行：先启用展示位置验证布局，再启用10日与次日两个门槛；正式声称本版完整上线时须覆盖全部用户确认位置和场景，不能将分批阶段写成全量完成。1.0.21审核、备案和冻结标签不变。

## 9. 单股整个页面分享

### 9.1 内容与入口

分享区作为独立卡片放在模拟计算之后、隐私与用户协议之前，与模拟区域明确分隔。标题“分享一下”及说明“分享当前股票状态与异动计算结果”与模拟计算标题/说明采用同一行排版；下方两个等宽横向按钮，高76rpx、间距20rpx，主按钮浅蓝色，朋友圈图标与文字同色。仅提供“发给好友”和“炫朋友圈”两个独立入口，使用微信官方WeUI图标素材；协议区原位置、42rpx上间距及样式不变。小程序不申请相册等系统权限，不提供保存图片功能。

分享内容为当前股票状态、四项预警及默认未填写的2日模拟计算。发送者即使已输入或展开10日，分享也重新使用原计算函数在独立副本上计算默认2日基线；输入显示为未填写“—”，不带出用户自定义值，不重置发送者页面。状态、预警、数据不可用和暂不适用提示仍按当前显示结果保留。白底细线、风险色与底部一行行情时间及公告依据保持不变。

搜索栏、搜索历史、广告、分享操作区及协议导航不进入结果图。生成过程在本地，不上传模拟输入、不保存用户结果到数据库或Redis。分享图片只交给微信原生分享能力处理；小程序不读取或写入相册、不申请系统权限。分享是可选功能，不奖励分享、不改变原有免费范围或广告许可。

### 9.2 微信渠道与打开后的初始态

- “发给好友”使用`button open-type="share"`原生小程序卡片，发送给朋友或群，使用当前股票状态＋四项预警动态封面；打开后进入该股默认态。
- “炫朋友圈”生成完整结果图片后打开微信原生`wx.showShareImageMenu`图片分享菜单，由用户在微信菜单选择朋友圈等目标；按钮不会绕过微信菜单直接发布朋友圈。按微信官方图片分享API能力，接收者入口按客户端实际支持显示。
- 右上角保留微信原生转发/朋友圈分享入口；原生小程序卡片用动态状态封面。底部图片分享操作负责朋友圈图片，不重复冒充原生页面转发。
- 朋友圈图片不保证携带可点击的小程序入口；需要可点击页面入口时使用右上角的“分享到朋友圈”。不伪造网页链接或二维码；暂不为此增加服务端小程序码生成服务。
- 本版将“进入小程序初始态”定义为：进入同一股票并读取当前可用数据，恢复默认2日、空白输入按0%计算；不复现发送者的模拟输入、10日布局或广告解锁。冷启动与已经打开小程序时均适用。普通切标签/返回的既有缓存策略不变。
- 入口仅包含股票代码与分享来源标记，不包含模拟参数、会话许可、接口授权token或身份信息。微信展示分享菜单的成功回调不能记为实际发送成功。

### 9.3 失败与验收

生成时按钮显示进度并合并连点；换股、跨业务阶段或页面销毁后，迟到的旧图片不弹出。取消不提示“分享成功”、不清空输入。导出失败可重试，旧客户端或图片菜单不可用时降级为完整图片预览，用户可长按操作；页面入口仍由原生分享菜单提供。

本地验收覆盖两种独立动作：朋友/群走原生卡片、朋友圈打开官方图片菜单；覆盖取消/接口失败及重试。还覆盖默认2日（发送者自定义10日也不带出输入）、未适用及不可用提示、无敏感字段、冷/热进入默认态、连点和换股竞态。微信客户端的实际好友/群/朋友圈发送、图片入口和双端阅读仍须真机验证。详见[分享本地验收](单股整页分享本地验收_20261113.md)。

官方依据：[wx.showShareImageMenu](https://developers.weixin.qq.com/miniprogram/dev/api/share/wx.showShareImageMenu.html)（2026-11-13核对）：基础库2.14.3支持图片菜单，3.2.0支持needShowEntrance/entrancePath，3.8.2支持朋友圈图片分享；文档仅明确好友图片的小程序入口，不将其扩写为朋友圈图片链接。
